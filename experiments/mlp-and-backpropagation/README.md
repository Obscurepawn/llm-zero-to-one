## 这次实验为什么要用“单层模型 vs 两层 MLP”

如果直接从公式讲多层感知机，初学者很容易只记住结构，却看不出它到底比线性模型多了什么。

所以这里故意放一个对照：

- 单层模型：`XW + b`，再接一个输出层激活
- 两层 MLP：`X -> Linear -> Tanh -> Linear -> Sigmoid`

如果把第 2 周的代码放进这个框架里看，会更清楚：

- 线性回归：`X -> Linear -> 连续值输出`
- 逻辑回归：`X -> Linear -> Sigmoid -> 概率输出`
- 两层 MLP：`X -> Linear -> 非线性 -> Linear -> 输出`

在非线性数据上，单层模型通常会失败，而两层 MLP 可以学出更弯的决策边界。这样你就能直接看到“隐藏层 + 非线性”到底带来了什么。

## 为什么示意图里画 2 个隐藏节点，但代码里用了更多

你会注意到，`single_layer_models_as_perceptrons.svg` 里只画了 2 个隐藏节点，而 `mlp_numpy.py` 里真正训练模型时使用的是：

```python
TwoLayerMLP(input_dim=2, hidden_dim=8, seed=1)
```

这两者并不冲突，它们服务的是两个不同目的：

- 图里画 2 个隐藏节点，是为了把结构讲清楚。
- 代码里用 8 个隐藏节点，是为了让训练更稳定，更容易把 XOR 数据学出来。

从教学上说，2 个隐藏节点已经足够帮助你理解“两层 MLP 为什么比单层模型强”：

- 隐藏层神经元会先学到不同的中间表示
- 输出层再把这些中间表示组合起来
- 非线性激活让这种组合不再等价于一条直线

但从训练实验上说，如果隐藏节点太少，模型虽然在理论上可能够用，实际训练时仍然可能因为初始化、学习率和数据噪声的影响而不够稳定。把 `hidden_dim` 设为 `8`，只是为了让这份教学代码更容易稳定收敛。

## 你运行后应该重点观察什么

### 在单层模型里

- 它本质上只能学出一条线性的分界面
- 在 XOR 这类非线性数据上，损失会下降到一定程度后停住
- 决策边界通常仍然是一条直线

### 在两层 MLP 里

- 隐藏层会把输入先映射到新的表示空间
- 激活函数会打破“纯线性变换”的限制
- 反向传播会把输出层的误差信号再传回隐藏层
- 模型能学出明显非线性的决策边界
