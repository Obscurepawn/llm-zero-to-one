# 第 2 周：线性回归、逻辑回归和损失函数

这个目录对应 12 周学习计划中的第 2 周，目标是把下面三件事真正跑通：

1. 理解什么是模型、参数、预测值和损失函数。
2. 理解梯度下降为什么能让损失逐步下降。
3. 区分回归任务和二分类任务分别该怎么建模。

## 目录结构

- `linear_regression_numpy.py`
  - 用 `NumPy` 手写线性回归
  - 损失函数使用均方误差 `MSE`
  - 对比不同学习率下的训练曲线
- `logistic_regression_numpy.py`
  - 用 `NumPy` 手写二分类逻辑回归
  - 损失函数使用二元交叉熵 `Binary Cross Entropy`
  - 输出分类边界和不同学习率下的损失曲线
- `run_all.py`
  - 一次性运行两个示例
- `outputs/`
  - 脚本运行后自动生成图片

## 推荐学习顺序

1. 先读 `linear_regression_numpy.py`
2. 再读 `logistic_regression_numpy.py`
3. 最后用 `run_all.py` 一次性跑通

原因很简单：

- 线性回归是最直接的“预测连续值”例子，先把训练流程学顺。
- 逻辑回归虽然名字里有“回归”，但实际用于分类；它更像是“在线性模型外面套一个 sigmoid，再配上交叉熵”。

## 如何运行

在当前目录执行：

```bash
python linear_regression_numpy.py
python logistic_regression_numpy.py
```

如果你想一次性都跑：

```bash
python run_all.py
```

## 你运行后应该重点观察什么

### 在线性回归中

- 模型形式是 `y_pred = XW + b`
- `W` 和 `b` 是需要学习的参数
- `MSE` 衡量“预测值”和“真实值”之间的平均平方误差
- 学习率太小，loss 会下降得很慢
- 学习率合适，loss 会稳定下降
- 学习率太大，loss 可能震荡甚至发散

### 在逻辑回归中

- 先做线性变换：`z = XW + b`
- 再通过 `sigmoid(z)` 把结果压到 `0` 到 `1`
- 输出值可以解释成“属于正类的概率”
- 交叉熵在分类任务里比 MSE 更常见，因为它直接惩罚“自信但错”的预测

## 建议你自己额外尝试的改动

1. 修改学习率，观察损失曲线形状如何变化。
2. 修改训练轮数，观察什么时候开始趋于稳定。
3. 修改数据噪声大小，观察拟合难度如何变化。
4. 在逻辑回归里改动分类阈值，比如从 `0.5` 改为 `0.7`，看准确率如何变化。
